# Memory systems survey

- This is a catalog of every external repo (60 of them) that the old `pogan-toolkit` project's research touched, plus the research papers and commercial products it named alongside them.
- Stars, last-push date, and archived status came from a live `gh api` pull run on 2026-08-21 (the six seed repos were re-pulled later the same day so this table and `seed-repos/` show identical numbers; star counts move by tens per hour) — this is the authoritative row list; nothing here was re-checked against the repos themselves in this pass.
- The "What it is" / "Strongest idea" / "Main weakness" columns are short summaries pulled from the old project's own research write-ups, not a fresh re-verification of the repos.
- "Old verdict" means whatever the OLD research decided (adopted / partial / study-only / rejected / none recorded) — it is a historical record and binds nothing about this project.

## Not in the table

Research papers with no shipped repo of their own:
- Self-Refine, Huang et al. ("LLMs Cannot Self-Correct Reasoning Yet"), ExpeL, Voyager, ACE (Agentic Context Engineering), Generative Agents/"Smallville", Darwin Gödel Machine, SICA, A-MEM, D-MEM
- Liu et al. "Lost in the Middle"; Han et al. and the GraphRAG-Bench papers; "Reliable Graph-RAG for Codebases" and its "Repository Intelligence Graph" companion; RAGSearch/"Do We Still Need GraphRAG?"; LazyGraphRAG (Microsoft Research's query-time half never shipped anywhere, unlike its "fast" extraction mode which did ship into `microsoft/graphrag`)

Commercial or closed products with no GitHub repo to study:
- Zep (the hosted product, distinct from the open `getzep/graphiti` engine), Cloudflare Agent Memory, Anthropic's memory tool (Claude API `memory_20250818`), Claude.ai's consumer "memories" feature, Anthropic Managed Agents' memory store, OpenAI Codex CLI, Cursor, Cognition's DeepWiki, Devin's "Knowledge" feature, Swimm, LangSmith (only its client SDK is public), Meta's Glean

Named in the research but not resolved to a GitHub URL, or named but excluded from the live 60-repo pull:
- AGENTS.md standard (a convention at agents.md, not one repo), Karpathy's "LLM Wiki" (a gist, not a repo), engRAM (no org/owner given anywhere), OWASP Agent Memory Guard (`OWASP/www-project-agent-memory-guard`), `a5c-ai/babysitter` ("genty"), SWE-agent's "Demonstrations" feature, mini-swe-agent, fast-graphrag (Circlemind), nano-graphrag, GraphRepo, `ryanwaits/drift`, `jbrockSTL/doc-drift`, DSPy (`dspy.ai`)
- Graph/storage engines evaluated as candidates but not in the live pull (SQLite itself was the final pick): Neo4j Community Edition, Memgraph, FalkorDB, oxigraph, NetworkX, Cozo, SurrealDB, TypeDB, libSQL/Turso, DuckDB+DuckPGQ
- AutoGen (`microsoft/autogen`) — the older framework `ag2ai/ag2` descends from; no separate URL given for it

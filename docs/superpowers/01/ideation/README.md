# docs/superpowers/01/ideation/

- This is the **scratchpad before brainstorming** for version 01. Ideas, notes, findings, recommendations.
- **Nothing here is ever a fact, a decision, or a requirement.** The moment the brainstorming session for version 01 starts, this whole folder is stale.
- Agents: read this for ideas. Never cite it as authority. Never "execute" anything in it — there is nothing to execute.
- Keep it non-technical. If a point needs real technical depth, it is probably a wiki fact (`docs/wiki/`) or it belongs in the spec that does not exist yet.
